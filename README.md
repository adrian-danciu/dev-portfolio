# Adrian Danciu — Developer Portfolio

Personal software engineering portfolio built with **React 19**, **TypeScript**, **Vite**, **Bun**, and [**@adrian-danciu/ink-ui**](https://www.npmjs.com/package/@adrian-danciu/ink-ui).

<img width="1081" height="774" alt="image" src="https://github.com/user-attachments/assets/31b1c961-3e74-40e9-9dda-b7ead1cbc31f" />

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **UI Library:** [`@adrian-danciu/ink-ui`](https://github.com/adrian-danciu/ink-ui) & `@adrian-danciu/ink-ui-tokens`
- **Package Manager & Runtime:** Bun

## Local Development

```bash
bun install
bun run dev
```

## Production Build

```bash
bun run build
bun run preview
```
